# Code of conduct

This project adopts the Contributor Covenant, version 2.1, as its code of conduct. The full text is
published at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/> and applies to every
space of the project: the repository, issues, pull requests, discussions and any channel where you
represent the project.

In short: be respectful, assume good faith, accept feedback gracefully, and keep the discussion on the
work. Harassment, discrimination and personal attacks are not accepted.

## Reporting

To report behaviour that breaks this code, contact the maintainers privately through the repository's
GitHub private reporting channel (the **Security** tab, **Report a vulnerability**, as described in
[SECURITY.md](SECURITY.md)) and mark the report as a conduct report. Do not post it in a public issue
or pull request. No personal e-mail address is published.

The maintainers review each report, keep the reporter's identity confidential, and apply the
enforcement guidelines of the Contributor Covenant 2.1.
